FAQ

Questions, answered

Do I need an OpenAI API key?

No. AskBase runs local embeddings and a demo extractive mode with zero API keys. Add any OpenAI-compatible LLM key when you want full generative answers.

What documents can I upload?

PDF, Word (.docx), plain text, Markdown, and CSV — plus direct import from any public URL. Scanned PDFs need OCR first (coming soon).

Will it hallucinate?

AskBase is grounded: it answers only from retrieved passages and says "I don't know" when nothing relevant is found. Every answer carries citations you can click to verify.

Is my data private?

Yes. Multi-tenant isolation means your documents are only ever searchable inside your own workspace. Public links are opt-in per knowledge base.

Can I use it on my website?

Yes — paste one script tag and you get a floating chat bubble powered by your knowledge base. Or use the REST API to build it into your own product.
